## Reading Order for the Minister

If the Minister has **3 minutes**: Section 01 only.
If **15 minutes**: Sections 01, 02, 07 (sensitivities), and any in-room talking points card (Section 05).
If **45 minutes**: 01–05 + 07–08.
If **full briefing session**: the whole pack, walked through by Chief of Staff + DG Asia.

## How to Use This Template

1. Copy this entire `briefings/templates/` directory into `briefings/case-studies/<YYYY-MM>-<host>-<visiting>-<portfolio>/`.
2. Fill in placeholders section by section.
3. Run the `minister-briefing-orchestrator` Claude Code agent to draft sections from a one-line trip spec, then human-edit.
4. Run Kai (`ambassador-kai-voss`) over Sections 01, 07, 08 for strategic sharpening before sign-off.
5. Print as Markdown; PDF rendering (`weasyprint`) is a future enhancement.

---

*Classification handling:* this Master Pack inherits the highest classification of any included section (typically `سري — Confidential`). Sections marked `محدود — Restricted` may be circulated wider per Section 00 distribution list.
