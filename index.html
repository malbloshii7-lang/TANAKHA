The genetic code of every prompt

D · N · A

Strip any world-class prompt down to its strands and you find the same three: Define the intent, Navigate the constraints, Adapt from the response. Master these and the ten perks below become muscle memory.

D

Define

State the role, goal, and audience before a single instruction. Ambiguity in → ambiguity out.
N

Navigate

Set the rails — format, length, tone, what to avoid. Constraints are creative fuel, not cages.
A

Adapt

Read the output, isolate the gap, and refine. The prompt is a dialogue, never a one-shot.

The 10 Mastery Perks

Tap “copy prompt” on any card

PERK 01

Assign a role before a task

Open with “Act as a…” The model inherits the vocabulary, standards, and judgment of the persona — answers sharpen instantly.

Best with Claude (Opus 4.8) ChatGPT Gemini
PERK 02

Show, don’t just tell

Drop in 1–3 worked examples (few-shot). The model mirrors your pattern far more reliably than it follows abstract description.

Best with Claude GPT-4o Mistral
PERK 03

Ask it to think out loud

Add “reason step by step” for logic, math, and planning. Visible reasoning catches its own mistakes before the final answer.

Best with Claude (extended thinking) OpenAI o-series DeepSeek-R1
PERK 04

Pin the output format

Demand JSON, a table, or markdown headings. Structure removes guesswork and makes results pipeable into the next tool.

Best with Claude (tool use) GPT (JSON mode) Gemini
PERK 05

Constrain to liberate

Box the answer — “in 50 words,” “no jargon,” “avoid X.” Tight limits force signal over filler.

Best with Claude ChatGPT Copilot
PERK 06

Feed it the ground truth

Paste the doc, data, or context the answer must rest on. Grounded prompts beat memory and slash hallucination.

Best with Claude (Projects) Perplexity NotebookLM
PERK 07

Iterate — never one-shot

Treat the first reply as a draft. “Make it bolder / tighter / for execs” — refinement is where mastery lives.

Best with Claude ChatGPT (Canvas) Gemini
PERK 08

Make it the critic

Ask the model to red-team its own answer: “List 3 weaknesses, then fix them.” Self-review compounds quality for free.

Best with Claude GPT-4o Grok
PERK 09

Set the visual DNA

For images, specify subject, style, lighting, lens, mood in that order. Precision in language is precision in pixels.

Best with Midjourney DALL·E 3 Stable Diffusion
PERK 10

Save what works as a template

A winning prompt is an asset. Parameterize it with {{slots}} and reuse — your personal compounding library.

Best with Claude (Prompt Library) PromptPerfect LangChain
