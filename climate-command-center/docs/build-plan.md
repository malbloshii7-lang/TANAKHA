# Plan: Ministerial-Grade Climate Command Center Campaign HTML

## Objective
Build a campaign HTML page inspired by the WMO SMART 2.0 reference site, but upgraded with:
- Ministerial-grade visual design and tone
- Real, updated World Bank Open Data for all metrics
- Black Swan risk analysis integration
- Superior interactivity and visual sophistication

## Stage 1 — Data Collection (Parallel)
### 1A — World Bank Climate Data
Load: `world_bank_open_data` plugin
- CO2 emissions (total, per capita)
- Renewable energy consumption (% of total)
- Climate vulnerable population
- GDP affected by climate disasters
- Early warning systems coverage
- Freshwater withdrawals
- Forest coverage
- Temperature anomalies

### 1B — Black Swan Risk Assessment
Load: `black-swan` skill
- Identify tail risks in climate finance
- Stress-test climate scenarios
- Generate risk alerts and hedge recommendations
- Portfolio concentration analysis for climate investments

### 1C — Web Scraping Reference Design
- Full screenshot capture of reference site for design elements

## Stage 2 — Build & Deploy
Load: `vibecoding-webapp-swarm` skill
- Single-page HTML with embedded CSS/JS
- Sections matching reference but enhanced:
  1. Hero (ministers-grade, cinematic)
  2. Strategic Framework (SMART 2.0 enhanced)
  3. Live Climate Risk Index with real WB data
  4. Strategic Alignment Matrix with animated charts
  5. Key Governance Events (updated dates)
  6. Global Partners & Endorsements
  7. Strategic Partnership Detail
  8. Black Swan Risk Dashboard (integrated from skill)
  9. CTA Footer
- Deploy as static site

## Output
